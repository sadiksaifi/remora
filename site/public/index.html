Questions and answers.

Is Remora free and open source?

Yes. Remora is free and open source under the GNU GPL v3. The source code is on GitHub.

Can I connect to a Windows PC from my Mac?

Yes. Remora connects to Windows over RDP, the protocol behind Windows Remote Desktop. Turn on Remote Desktop on the PC, then add its address in Remora. The PC needs Windows Pro, Enterprise or Education. Windows Home cannot accept Remote Desktop connections.

Can I connect to Linux?

Yes. Remora connects to Linux desktops that serve RDP, such as GNOME Remote Desktop, and to VNC servers.

Can I connect to another Mac?

Yes. Turn on Screen Sharing on the other Mac, and Remora connects to it over VNC.

Which AI agents can use Remora?

Any agent that can run the remora CLI can use it. Remora installs a skill for Claude Code, Codex, OpenCode, Cursor, or any other agent.
